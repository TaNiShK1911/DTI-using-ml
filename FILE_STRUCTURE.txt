================================================================================
WORKFLOW
================================================================================

1. SETUP
   └─> python setup.py
       └─> Installs dependencies
           └─> Creates directories

2. PREPROCESS
   └─> python run_preprocessing.py
       └─> Loads BindingDB TSV
           └─> Cleans & validates data
               └─> Creates train/val/test splits

3. TRAIN (Optional)
   └─> python run_training.py
       └─> Loads processed data
           └─> Trains DTI model
               └─> Saves best model

4. DEPLOY
   └─> python run_backend.py (Terminal 1)
       └─> Loads trained model
           └─> Starts API server
   
   └─> cd frontend && npm run dev (Terminal 2)
       └─> Starts dev server
           └─> Opens browser

5. USE
   └─> http://localhost:3000
       └─> Enter SMILES & sequence
           └─> Get predictions
               └─> View results
